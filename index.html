Aprende

¿Qué es HTML?

HTML es el lenguaje que describe la estructura de una página. Usa etiquetas como <h1>, <p> y <div>.

<h1>Hola mundo</h1>
<p>Mi primera página</p>
¿Qué es CSS?

CSS le da estilo: colores, tamaños, márgenes, fuentes.

body {
  background: #0a0a0a;
  color: white;
}
¿Qué es JavaScript?

JavaScript le da comportamiento: reaccionar a clics, calcular, mostrar datos.

const nombre = "Ana";
console.log("Hola " + nombre);
¿Qué es una variable?

Un espacio con nombre donde guardas un valor.

let edad = 15;
const nombre = "Luis";
¿Qué es una función?

Un bloque de código que puedes reutilizar.

function saludar(nombre) {
  return "Hola " + nombre;
}

console.log(saludar("Ana"));
¿Qué es una API?

Una API es un contrato para pedir datos o servicios a otro programa. Cuando escribes una dirección como /api/saludo, estás llamando a una ruta de una API.

¿Qué es HTTP?

Es el protocolo con el que tu navegador pide cosas al servidor. Métodos comunes: GET (pedir), POST (enviar), PUT (actualizar), DELETE (borrar).

        💡 Ver pista
        
Cuando sumas un número con un texto, JavaScript concatena en lugar de sumar. El resultado es "52", no 7.

      


      

        ✅ Ver solución
        
function sumar(a, b) {
  return Number(a) + Number(b);
}

console.log(sumar(5, "2")); // 7

IA para programar

      
La IA debe ayudarte a entender, no a copiar. Aquí tienes cómo pedir ayuda bien.


      
Plantilla de prompt

      
Estoy aprendiendo JavaScript.

Este es mi código:
[pega tu código]

Este es el error:
[pega el mensaje exacto]

Explícame:
1. Qué significa el error.
2. En qué línea ocurre.
3. Cómo puedo investigarlo.
4. Dame una pista antes de mostrarme la solución.
5. No reescribas todo el programa.


      
Reglas de oro

      
    
        
  • Pide pistas, no respuestas completas.
    • 
        
  • Pide que te explique el código corregido, no solo que lo reemplace.
    • 
        
  • Nunca pegues datos personales ni contraseñas.
    • 
        
  • Si no entiendes la respuesta, pide que te la explique con una analogía.
    • 
      


      
Herramientas gratuitas

      
    
        
  • Ollama → corre modelos de IA en tu computadora, sin enviar datos a servidores.
    • 
        
  • ChatGPT / Gemini / Claude → gratis en su versión básica, pero envían tus datos a sus servidores.
    • 
        
  • Copilot → sugerencias dentro del editor.
    • 
      

      
"Gratis" no siempre significa "sin internet". Una IA en línea es gratis pero envía tu consulta; una IA local (como Ollama) trabaja en tu equipo después de descargar el modelo.

    


    
    

      
Diccionario

      

        
Variable
Espacio con nombre donde guardas un valor.

        
Función
Bloque de código reutilizable.

        
Error
Problema que impide que el código funcione como esperas.

        
Depurar
Encontrar y corregir errores en el código.

        
Consola
Herramienta donde ves mensajes del programa.

        
Endpoint
Dirección de una API donde pides algo.

        
API
Contrato para pedir datos o servicios.

        
PWA
Aplicación web instalable, con funciones parecidas a una app nativa.

        
Service Worker
Script que permite que la app funcione sin conexión.

        
Backend
Parte del sistema que corre en el servidor.
